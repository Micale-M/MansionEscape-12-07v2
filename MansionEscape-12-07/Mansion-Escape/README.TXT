Project: zuul-bad
Authors: Michael Kölling and David J. Barnes

This project is part of the material for the book

   Objects First with Java - A Practical Introduction using BlueJ
   Seventh edition
   David J. Barnes and Michael Kölling

The premise of the game is to escape the mansion you find yourself trapped in.
By traversing rooms and using clues and items, the player will be able to make
their grand escape. Although there's no monsters lurking about, the player can 
lose if they fail to many times to get the front door open. There are health 
recovery items in the form of food. There is also a feature that lets the player
how many actions they've taken after the game is over, regardless of if they
win or lose.
